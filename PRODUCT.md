# DildoVander

## Product truth

DildoVander is a theatrical suitcase with six wand compartments and an independent
ESP32-S3 controller. Its owner operates and diagnoses it from an iOS-first companion.
Visitors retrieve stories and digital interpretations through the public evening
page; private portraits and administrative actions retain their own authorization.
Engineers inspect CAD, assembly, simulation and observer telemetry.

## Platform and stack

Existing TypeScript/Vite + Capacitor mobile application, static HTML/JavaScript
public pages and simulator, generated offline CAD viewer, ASP.NET Core backend
and ESP-IDF firmware. Reuse these architectures. Web rendering is not native iPhone
or hardware acceptance. Czech text and diacritics must remain readable.

## Invariants

Preserve safety/Stop and lease boundaries, protocol contracts, legacy catalogue records,
consent and manual deletion. Unknown, simulated and measured state are distinct.
CAD geometry, scale and physical materials are engineering truth. No paid model
calls, deployment or hardware actuation follows from visual implementation.

Source: owner's Vapour Chrome implementation brief, repository AGENTS.md and
current application contracts. Visual decisions live in the shared design system.
