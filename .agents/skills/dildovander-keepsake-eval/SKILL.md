# DV10 keepsake evaluation

Use for DV10 acceptance and regressions. Read the owner's current specification,
the relevant backend contracts and `kufr/web/README.md`. Preserve the actual source,
artifact and schema versions. Do not treat an older result as a current check.

Default dry-run is offline deterministic fixtures plus the explicitly synthetic
browser suite: `python -m unittest discover -s kufr/web/keepsake -p 'test_*.py'`
and `node kufr/web/keepsake/test-browser.cjs` with available Playwright runtime.
Run relevant backend tests through their existing project command. Keep fake
payloads in tests, never in published portal files.

Check exact outcome/catalog mapping, edition story/design agreement, no real-prop
claims, partial/error/provider-unknown states and honest synthetic labels. Inspect
exports for consistent versions and no credentials, operation IDs or private URL.
Check claim/recovery/share scope including an owner browser opened in share view,
multiple grants, expired access and stale route/poll responses. GET must not
generate. Check no browser storage, analytics, foreign scripts or secrets in logs.

For portrait verify local preview before upload, explicit consent, type/size errors,
separate cancel/revoke/delete and no portrait in standard ZIP or public share.
Evaluate cleanup receipts separately for local/provider/backup and late results.
Inspect the actual 320/390/430 px, landscape/desktop, keyboard, 200% zoom and
reduced-motion rendering. Real iPhone acceptance remains a separate evidence gate.

Paid provider evaluation runs only with explicit approval covering the concrete
inputs and scope. Ten synthetic variants cannot prove OpenAI individuality.
Visual inspection and request-boundary evidence are both needed for real AI output.
Report complete/partial/blocked, exact executed commands, source files, fixture
provenance, findings and remaining acceptance gaps. Never mark an unrun test PASS.

New tracked skills require a fresh task/catalog reload to appear in discovery.
During the current task read the file directly; writing it does not prove hot reload.

The owner approved static pickup at `/keepsake/evening/`; read `kufr/docs/dv10/STATIC_EVENING.md` for precedence. Shared wands/stories are scoped to the configured device and captured active evening. Public browsing never grants owner/photo/admin rights. Preserve manual retention and read-only GET behavior.
