# Connection notes

Use connected Linear and the GitHub identity selected by the account router.
Do not provision a tracking App, Project token or replacement service. Optional
context helpers are not prerequisites for ordinary issue/document retrieval.

Before native association, verify Issues Sync is off, public linkback comments
and description publication are disabled, and a controlled pilot leaves the
public PR clean. Otherwise attach a generic PR URL privately and update status
explicitly. An attachment does not prove native automation.

Read the destination after an uncertain mutation before retrying. Never create
duplicate issues, documents or comments to resolve a timeout.

An outage permits already-owned isolated local work. Resolve overlap with its
lead and preserve a compact handoff; never create a public fallback.
Retire tracking-only credentials only after verifying every actual consumer.
Deployment/source-read credentials, runner controls and operational evidence stay
under their separate authority.
