# Firmware Obludária

Projekt PlatformIO pro Arduino Nano s ATmega328P a novým bootloaderem. Pro sestavení spusťte v této složce `pio run`. Pokud objednaný klon používá starý bootloader, bude třeba před nahráním změnit variantu desky v `platformio.ini`.

Program je zatím pouze startovní kostra. Implementace začne po dokončení kufru a ověření mechaniky knihy.
