# Obludné obludárium — pozdější projekt

Samostatná animatronická kniha bez AI. Záměr: občasné vrčení a pohyb v klidu, reakce na přiblížení a krátké otevření/zavření při blízkém kontaktu. Pohyblivé části potřebují měkké dorazy a omezenou sílu.

Zvolený vnější základ: [plyšové Obludné obludárium 32 cm](https://www.pricnaulice.cz/plysove-obludne-obludarium-32-cm-harry-potter/). Jeho vnitřek a uchycení mechanismu je potřeba prohlédnout před finálním výběrem pohonu.

[`firmware/`](firmware/) je připravený jako samostatný projekt PlatformIO pro Arduino Nano. Zatím jde pouze o startovní kostru bez zapojení senzorů nebo motorů. K implementaci a nákupu specifických dílů se vrátíme až po dokončení kufru a prohlídce skutečné plyšové knihy.

Seznam dílů je v [`docs/elektronika.md`](../docs/elektronika.md).
